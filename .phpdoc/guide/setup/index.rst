.. title:: Setup

Setup
#####

Here you will find information about the requirements, installation, configuration, upgrade, and maintenance of the
Post Office.

The Post Office only manages the database of your mail server. To actually send and receive emails, Postfix and
Dovecot have to be configured to use that database as described in :doc:`Mail Server <../mailserver/index>`.
